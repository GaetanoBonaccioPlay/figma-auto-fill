# Profili di base

Ogni file `.json` di questa cartella diventa un Profilo di base, compilato nel plugin a ogni build (ADR 0002).
Una build fallisce se un profilo non è valido o contiene Abbinamenti confermati.

Il repository è pubblico: un Profilo di base messo qui rende pubblici il nome del Brand e la struttura dei suoi
Excel (fogli, intestazioni, Etichette ricorrenti). Per i Brand dei clienti usa invece Profili personali, condivisi
tra colleghi con **Esporta** e **Importa** dal plugin.
